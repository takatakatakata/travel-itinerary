北海道登別旅行

2026-11-08 — 2026-11-10

02 / STAY

宿泊先

全日程共通

・宿泊先は「リブマックスリゾートウポポイ白老温泉」。予約済み。 ・宿泊プランは朝夕付き。 ・朝食の時間は7:00～10:00。基本的には7:00とする。 ・夕食の時間は17:30～21:00。基本的には17:30とする。 ・15時チェックイン、11時チェックアウト。

03 / ESSENTIALS

旅のメモ

  • 宿泊先は11月8日・9日とも「リブマックスリゾートウポポイ白老温泉」で予約済み。朝夕食付き。朝食7:00～10:00、夕食17:30～21:00、チェックイン15:00、チェックアウト11:00。
  • 宿の住所は北海道白老郡白老町東町4-6-1。白老駅正面口から徒歩約10分。
  • 往路は11月8日成田09:30発、復路は11月10日新千歳18:10発の予約済みJetstar便。予約内容で便名とターミナルを確認する。
  • 2日目は宿を8:30以降に出発し、白老駅前から登別温泉行き直通バスを利用する計画。
  • JR移動は可能な限り普通列車を利用。3日目は空港で過ごす時間を確保し、帰りの便に余裕を持って戻る。
04 / CHECK

出発前に確認

  • Jetstarの公式冬期時刻表では往路09:30発はGK107・11:20着、復路18:10発はGK116・19:55着に該当する。予約内容の便名・ターミナルと照合する。
  • JRの列車時刻は確認時点の公開時刻表を参考にした提案で、11月8日・10日のダイヤと乗換は確定扱いにしていない。特に往路の南千歳12:59接続と復路の南千歳13:23接続を出発前に確認する。
  • 道南バスの白老駅前10:38発・登別温泉15:15発は公開時刻表を参考にした提案。11月9日の運行、停留所位置、運賃を確認する。
  • 往路便が約30分遅れた場合、空港での昼食を短くしても12:39発のJRに間に合わない可能性がある。その場合は後続列車を確認し、15:00チェックインや博物館見学時刻の遅れを見込む。入力された航空便の時刻と宿の条件は変更しない。
  • 11月8日の博物館見学は短時間。航空便や鉄道の遅延時は、ウポポイの17:00閉園と博物館の最終入館時刻を確認する。
  • 11月9日のクマ牧場の営業、ロープウェイ運行、天候による休園の有無を事前に確認する。
  • 宿の朝夕食の利用枠と、両日の17:30夕食希望を宿泊予約内容で確認する。
