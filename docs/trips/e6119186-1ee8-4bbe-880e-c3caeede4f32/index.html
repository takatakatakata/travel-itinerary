北海道登別旅行

2026-11-08 — 2026-11-10

北海道登別旅行のしおり（2026年11月8日～10日）。往復の予約済みJetstar便の出発時刻を保持し、1日目は15:00に白老の宿へチェックインしてから国立アイヌ民族博物館へ。2日目は白老から直通バスで登別温泉へ行き、夕食後は登別駅経由で宿へ戻る。3日目は11:00にチェックアウトし、早めに新千歳空港へ向かう。

02 / STAY

宿泊先

全日程共通

・宿泊先は「リブマックスリゾートウポポイ白老温泉」。予約済み。 ・宿泊プランは朝食のみで、夕食は外食する必要あり。 ・朝食の時間は7:00～10:00。基本的には7:00とする。 ・15時チェックイン、11時チェックアウト。

03 / ESSENTIALS

旅のメモ

  • 宿泊先：リブマックスリゾートウポポイ白老温泉。11月8日・9日の2泊とも予約済み。
  • 宿泊プランは朝食のみ。朝食提供時間は7:00～10:00、基本の朝食時刻は7:00。夕食は別途必要。
  • 宿のチェックインは15:00、チェックアウトは11:00。
  • 往路：11月8日、成田空港9:30発の予約済みJetstar。復路：11月10日、新千歳空港18:10発の予約済みJetstar。
  • 持ち物：航空券の予約情報、本人確認書類、防寒着、歩きやすい靴。
04 / CHECK

出発前に確認

  • 出発前に予約情報でJetstarの便名・ターミナル・最新の発着時刻を照合する。公式時刻表では往路9:30発がGK107、復路18:10発がGK116として掲載されている。
  • JRと道南バスの掲載時刻が11月8日～10日の運行日に適用されるか、ダイヤ改正・運休情報を出発前に再確認する。列車とバスの予約は入力されていない。
  • 1日目の飛行機が大幅に遅れると、ウポポイの17:00閉園までに博物館を十分見学できない。特に15:00チェックインと博物館見学の両立は当日の到着状況で判断する。
  • 2日目は登別温泉18:00発のバスから登別駅18:40発の特急へ乗り換える計画。バスが大幅に遅れた場合は次の列車を確認する。
  • のぼりべつクマ牧場は強風などでロープウェイが運休する場合があるため、当朝の営業状況を確認する。
  • 白老・登別温泉の夕食候補は席や当日の営業を確保していない。営業時間、休業、予約の要否を確認する。
  • 3日目に千歳市内へ途中下車する場合は、往復の交通時刻を確認し、新千歳空港16:10ごろの搭乗手続きに間に合う範囲に限る。
